YL-Lite(运来Pro 逆向成果的自研版本)的**本机构建产物**。

## 安装与使用

1. 安装 `dist/YL-Lite-v3.1.0-debug.apk`(Android 7.0+,允许未知来源)
2. 打开 App → **打开无障碍设置** → 启用"YL-Lite 抢福袋服务"
3. 打开抖音并登录 → 进入有福袋的直播间
4. 回控制台 → **开始抢福袋**(或用悬浮条);控制台实时显示统计与日志
5. 停止:控制台/悬浮条"停止",或系统设置关闭无障碍服务

## adb 控制(调试)

```bat
adb shell am broadcast -a com.yllite.app.START      # 启动监听
adb shell am broadcast -a com.yllite.app.STOP       # 停止
adb shell am broadcast -a com.yllite.app.DUMP_ON    # 观察模式(节点 dump 到 logcat tag=YLDump)
adb logcat -s YLDump:I YLBot:I
```

## 构建

```bat
set "JAVA_HOME=D:\develop\android\jdk\jdk-17.0.2"
set "GRADLE_USER_HOME=D:\develop\android\gradle-home"
D:\develop\android\gradle\gradle-8.7\bin\gradle.bat -p D:\develop\yl-lite-apk assembleDebug
```

产物在 `app\build\outputs\apk\debug\`。版本号在 `app/build.gradle`。
模拟器校验要点:重装 APK 后必须先 `settings delete secure enabled_accessibility_services`
再重新写入,否则系统沿用旧 ServiceInfo(手势能力不生效)且可能出现僵尸绑定。

## 真机验证记录(2026-11-09, Redmi K20 / Android 11 / 抖音 41.0.0)

端到端验证（截图+logcat 双证据，日志 tag=YLBot）：

| 环节 | 结果 |
|------|------|
| 无障碍绑定 | `capabilities=33`(读取内容+手势) ✅ |
| 直播间识别 | `在抖音直播间内(说点什么...)` ✅ |
| 福袋图标结构识别 | 无文本自绘 View 定位到 `(82,365)` ✅（同区域「电商优惠券」Button 靠无标签条件排除；两图标位置会互换，故不能按坐标写死） |
| 手势点击 | `>> 手势点击福袋图标(82,365)` 打开超级福袋弹窗 ✅ |
| 福袋弹窗 | **超级福袋为字节 H5/自绘渲染，无障碍树完全不可见**（仅背景层 `D=[关闭]`），⚠️「一键发表评论」任务按钮机器人点不到 |
| 参与 | 手动补点任务按钮后：`已成功参与` 吐司 + 图标变「已参与」+ `任务已完成 等待开奖` + 55 人参与 ✅ |

其他真机实测修正（均已落入代码）：
- **事件静默盲点**：H5 弹窗遮挡评论框后无障碍事件停止 → 增加 900ms 定时扫描看门狗（原版 Auto.js 的 while 轮询思路）
- **弹窗关闭防误伤**：价格文案 `¥` 会误触发；关闭按钮必须在屏幕中部区域（直播间右上角 X = 退出）
- **互动误报**：评论区事件文案("xxx分享了直播")不再当按钮点，且互动仅在直播间锚点存在时生效
- **引导弹窗**：`不感兴趣/以后再说` 自动清理
- 重装 APK 后必须 `settings delete secure enabled_accessibility_services` 再写入，否则沿用旧 ServiceInfo（无手势能力/僵尸绑定）
